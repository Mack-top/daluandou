# 《食灵月城》内容设定集 —— 鼎月城 · 失味之灾

> 面向《没食大乱斗》的世界观扩展设定。与现有内容（食灵：青团 / 蓝纹奶酪 / 冬阴功；怪物：巡夜灯灵 / 雾隐食客 / 月桥守卫；关卡：初春试炼 → 茶庭小径 → 石桥夜雨 → 月下酒窖 → 钟塔回廊；系统：占星、研制坊、滋味卡包、六槽装备）完全兼容，为其补全因果与纵深。

---

## 一、世界观总纲

**鼎月城**：一座以「九桥连月、一鼎定味」闻名的古城。城中央的**天地鼎**日夜熬煮着全城的食气——凡人烹调时升起的香气与念想。食气入梦，凝成**食灵**（传世名馔的魂魄所化，皆为少女之形）；食气被遗忘，则凝成**馔妖**（本设定中的怪物）。

**失味之灾**：十年前的一个满月夜，天地鼎无声熄灭了一角。被遗忘的味道开始化为最深的饥饿——馔妖夜行，食客失味，名厨忘技。玩家是**掌灶人**：能听见食灵之声的厨者，持一枚**味契**，与食灵缔约并肩作战，重燃天地鼎。

**核心命题**：*被遗忘的味道不会消失，它只是在等人想起。*——这句贯穿主线：怪物的执念、Boss 的怨、隐藏 NPC 的秘密，全部围绕「记住一道菜、一个人、一段夜」展开。

**元素体系**（对齐现有食灵）：自然 / 水 / 火 / 雷 / 光 / 影。馔妖同样带元素属性，克制关系与战斗引擎的 resistance 口径一致。

## 三、Boss 图鉴（5 个 · 章节梯度）

> 设计原则：每章一个「机制关键词」，复杂度线性上升：**单体机制 → 环境切换 → 行动条 → 镜像博弈 → 团队协作**。

### 第一章 · 贪味饕童 · 囡囡
- **外形**：抱着一只比自己还大的描金食盒的孩童虚影，双颊圆红，嘴角挂着到耳根的笑，食盒缝里伸出无数小手。
- **能力**：每回合自动**吞噬我方一个增益**，吞下的增益化为自身护盾。
- **攻击方式**：「还想吃！」扑抱（单体高伤）；「分你一口」把偷来的增益吐回给我方最弱单位（负 buff 化）。
- **弱点机制（喂食）**：主动丢弃一件食物类道具可诱其开盒僵直一回合，僵直期间护盾消失、受伤翻倍。**教学意义**：教会玩家道具不是只能嗑的。
- **剧情钩子**：囡囡是灾变之夜饿死的乞儿之念，收服净化后成为第三章茶寮的小帮工（NPC 化）。

### 第二章 · 双勺判官 · 咸与淡
- **外形**：一对连体双生厨官——左位「咸爷」着玄色袍，持一柄盐勺；右位「淡姑」着素色袍，持一柄清汤勺。共用一具身躯，轮到谁谁睁眼。
- **能力**：**味性切换**——每逢双数回合全场切换「咸境」（我方持续掉血）/「淡境」（敌方获得减伤）。切换前的回合有明确前摇提示。
- **攻击方式**：「咸浪」全体盐蚀；「淡雾」驱散我方增益；连体合击「一碗端」。
- **弱点机制（错位）**：在「咸境」中使用水系技能会被「化盐」反噬自身；正确解法是咸境用甜系（对咸判官伤害翻倍）、淡境用辛香系。**教学意义**：看环境打牌，不再无脑甩技能。
- **剧情钩子**：二者生前是御膳房争灶的师兄弟，失味之夜谁也尝不出对方的手艺，抱憾化妖。

### 第三章 · 醉月酒仙 · 壶中翁
- **外形**：一尊行走的青铜酒壶，壶嘴呵出的酒气凝成半透明的醉汉长袍，腰间挂满小酒盅，走路画着波浪线。
- **能力**：**行动条扰动**——全体我方行动条随机前进/后退；每三回合「筛酒」造成全场酒火（灼烧 + 已灼烧单位眩晕）。
- **攻击方式**：「一壶倒」单体灌醉（跳过行动）；「杯盘狼藉」弹射多段酒盅；「月下独酌」回复自身并强化。
- **弱点机制（清醒）**：使用驱散/解控技能命中他，可令其「酒醒」两回合——醒着的壶中翁防御与速度大降，且会羞愧地停止扰动。**教学意义**：控制链的时机比数量重要。
- **剧情钩子**：他本是天下第一酿酒师，失味之夜酿出的酒再无人喝得出来——连他自己也尝不出。酒窖里千坛封存的都是「没被人尝过的味道」。

### 第四章 · 雾厨 · 无名氏
- **外形**：一身惨白厨师服的高大人影，没有脸，只有一顶高帽与一双永不停下的手；身后跟着一整面墙的悬浮锅铲。
- **能力**：**镜像博弈**——开场复制我方攻击力最高的食灵为其「影厨」（属性 120%），影厨不灭则本体受伤减 70%。
- **攻击方式**：影厨使用被复制食灵的技能；本体「颠勺」把单个食灵铲离战场一回合；「试味」无视防御的固定真伤。
- **弱点机制（记忆）**：每命中本体一次，他恢复一段味觉记忆（浮现一段剧情残影）；记忆集满五段后现出真身——原来他是在灾变中失去味觉、连自己拿手菜名字都忘掉的第一代掌灶人弟子。真身受创翻倍。**教学意义**：Boss 战即叙事，打他就是在读他的故事。
- **剧情钩子**：他是终章 Boss 的「引路人」——记忆集满后亲手递给玩家一把钥匙：钟楼顶的密室。

### 终章 · 空鼎之主 · 忘川馔
- **外形**：天地鼎的巨大化妖影，鼎身缠满桌布残片，鼎口喷出的不是火而是「白茫茫的忘川雾」；雾里漂浮着半消散的宴席残影。
- **能力**：三阶段——**餐前**（忘川雾全队降命中，需靠灯火类增益抵抗）；**上菜**（召唤前四章 Boss 残影轮番登场）；**散席**（狂暴「饿啸」，每回合吞噬场地，可用空间逐回合缩小）。
- **攻击方式**：「忘席」吞掉我方一个技能位；「残宴如梦」全体幻伤；「散席之嗝」击退全体。
- **弱点机制（团圆）**：唯一破防条件——**全队四名食灵同时存活且血量均高于 30%** 时，鼎身浮现「团圆纹」，此时攻击才有效。**教学意义**：把整部游戏的养成观（活着、平衡、互相照应）打成一个 Boss 机制。
- **剧情真相**：忘川馔不是恶妖，它是「全城被遗忘的最后一道菜」——灾变之夜全城人都在逃难，那桌年夜饭没人吃。重燃天地鼎的方法不是打败它，而是**坐下来，把它吃完**。

## 六、场景图鉴（8 处）

> 章节顺序 = 玩家行进路线。每处含：环境氛围 / 布局要点 / 隐藏要素。

### 第一章 · 春山茶庭
- **氛围**：晨雾未散的梯田茶园，茶香混着青团甜气，远处春山如黛，近处石灶冒白汽。整体色调用「晨雾青 + 嫩芽绿」。
- **布局**：环形茶园路径 → 中央石灶广场（Boss 战场地）→ 后山采茶小径。新手期单线不迷路，但路径两侧藏交互点。
- **隐藏要素**：雾散的十分钟内（现实时间）出现**彩虹茶寮**——囡囡的小吃摊，限时折扣商店；茶田第七垄往下挖可得菜谱残页之一。

### 第二章 · 石桥夜雨
- **氛围**：雨夜九连环石桥群，桥灯次第亮起又被雨打湿，水面倒映双月（天上一轮、水中一轮）。色调「墨青 + 暖灯黄」。
- **布局**：九座桥串珠式排布，每桥一拨守卫；第 5 桥有岔路下桥洞（低洼被淹，需水系食灵）。桥面湿滑（位移技能加成）。
- **隐藏要素**：第 3 桥桥洞里躲雨的醉酒坛灵可**对话避战**（递它一把伞……任何雨具类道具）——它醒来会指认第 7 桥的假栏杆，后面是密室（菜谱残页之二）。

### 第三章 · 月下酒窖
- **氛围**：千坛封存的地下窖宫，酒气凝成银河般的悬浮光带，脚步声都会激起「回音涟漪」。色调「琥珀金 + 酒红」。
- **布局**：三层环降式酒架迷宫，中央是「回声坛阵」。壶中翁 Boss 战在窖底月池。
- **隐藏要素**：敲击特定酒坛有回声谜题——按「咸、淡、辣、甜、苦」五味顺序敲，开「五味龛」（菜谱残页之三 + 醉仙小盅）；喝了酒窖最深处的「没被尝过的酒」是触发壶中翁彩蛋（醉仙小盅）的前置。

### 第三章末 · 钟塔回廊
- **氛围**：百口铜钟悬成的长廊，风过钟自鸣，声音可见（声波以淡金色涟漪呈现）。庄严肃穆中带一丝森然。色调「古铜 + 玄黑」。
- **布局**：一条长直廊 + 两侧钟室岔间；尽头钟楼顶（第一代掌灶人残念出现点）。
- **隐藏要素**：按鼎月城民谣《九月桥》的旋律顺序敲钟（说书人处可学），开钟心密室——菜谱残页之四 + 百钟铜屑宝库。

### 第四章 · 雾隐后厨
- **氛围**：无名氏的巨大厨房迷宫：锅是池、灶是山、悬浮的锅铲与菜刀如林间飞鸟，蒸汽白雾终年不散。色调「惨白 + 铁灰」。
- **布局**：三大厨区（冷房 / 灶山 / 洗碗池瀑布）非线性的三选一推进，各区通向中央试味台（Boss 房）。
- **隐藏要素**：在冷房把冻住的冰髓甜魄**用光元素唤醒**（而非击杀）可收服为临时伙伴，它带路直达试味台密道（菜谱残页之五）。

### 终章 · 鼎月天台 · 星轨祭坛
- **氛围**：与 star-ascension 立绘同一处：夜空星轨低垂，悬浮玉祭坛居中，甜点化作星辰环绕，脚下云海翻涌。全游戏视觉最高点。色调「深蓝紫 + 星金」。
- **布局**：玉祭坛为圆心，六条星桥放射通向六章记忆回放点；中央可仰望天地鼎。
- **隐藏要素**：**星象对齐小游戏**——转动祭坛四周四尊星兽雕像，令星轨连成「北斗食杓」形，天降星光雨（全队经验加成 buff，菜谱残页之六）。

### 主城 · 夜市千灯
- **氛围**：永夜的美食长街，千盏食灯，蒸汽与吆喝齐飞，是全城「没有失味」的最后角落。所有 NPC 汇聚于此。色调「暖橙 + 灯红」。
- **布局**：一条主街 + 六个功能巷口（对应研制坊/时光屋/集市/占星/世界树/交易坊）；街尾是码头，可远眺九桥。
- **隐藏要素**：无名馄饨担只在**游戏内深夜**（主城时钟 23:00-1:00）出现在巷尾；对它连续交互七夜，第八夜它请你吃一碗馄饨——菜谱残页之七，并开启隐藏商店。

### 异空间 · 忘川宴席
- **氛围**：终章 Boss 战场地：漂浮在忘川雾上的残破宴席，冷掉的菜还冒着将散未散的热气，座椅空了大半。全游戏唯一「安静」的战场。色调「灰白 + 一点烛红」。
- **布局**：一张无限延展的圆桌，可用空间随「散席」阶段被雾吞噬而收缩；桌心正对空鼎。
- **隐藏要素**：战斗前可在桌上「落座」（互动），每个空位坐一次解锁一段全城人的回忆；集齐全部座位后，终战可解锁「吃席」结局而非「讨伐」结局（菜谱残页之八在此）。

## 七、关联性总网

**主线因果链**：
第一代掌灶人忘了一道菜（因）→ 天地鼎熄一角 → 失味之灾 → 无名氏（他的弟子）失忆成雾厨 → 忘川馔诞生（那道被遗忘的菜本身）→ 玩家重燃天地鼎（果）。**打败终章 Boss 的方式是「想起并吃掉它」**——世界观命题「被遗忘的味道只是在等人想起」在此闭环。

**跨类别钩子**（各举三例，其余见上文）：
- 囡囡（Boss）→ 净化 → 茶寮小帮工（NPC）→ 每日送醒神茶（物品）→ 壶中翁战（Boss）必备
- 无名馄饨担（NPC）→ 七夜彩蛋 → 失传菜谱（物品）→ 八场景隐藏要素（场景）→ 佛跳墙 · 尊者（隐藏食灵）
- 说书人（NPC）→ 教钟序民谣 → 钟塔回廊密室（场景）→ 百钟铜屑（物品）→ 徽记强化（系统）

**元素克制闭环**：水克巡夜灯灵/醉酒坛灵；火克雾隐食客/汤勺泥偶/冰髓甜魄；雷克月桥守卫；光唤醒冰髓甜魄/对抗忘川雾——**每章关卡的地形（雨/雾/酒气/钟声）都会放大或削弱对应元素**，配队即解谜。
