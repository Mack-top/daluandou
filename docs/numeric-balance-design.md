## 二、经验系统（修复孤儿表，接入升级）

### 2.1 经验曲线（分段几何，平滑无断崖）

```ts
function expRateAt(L: number): number {
  if (L < 31) return 1.05;   // 新手期：任务链驱动，曲线让位于节奏
  if (L < 61) return 1.06;   // 中期：与旧行为衔接
  return 1.07;               // 后期：放缓但不设墙
}
function expRequiredAt(L: number): number {
  if (L >= 100) return 0;    // 满级封顶标记（100+ 见 §2.5）
  return Math.max(10, Math.round((80 * expRateAt(L) ** (L - 1)) / 10) * 10);
}
```

| 等级 | 单级需求 | 分段累计 | 节奏（日 20 战 + 任务/挂机 40% 加成） |
|---|---|---|---|
| 1 / 10 / 30 | 80 / 120 / 330 | 1–30 共 5,290 | 0.01–0.05 天/级（首日 12–15 级目标达成） |
| 45 / 60 | 1,040 / 2,490 | 31–60 共 36,330 | 0.05–0.08 天/级（首月 60 级） |
| 70 / 90 / 99 | 8,520 / 32,980 / 60,630 | 61–100 共 860,600 | 0.4–0.94 天/级（满级周期 4–6 周） |
| 全程 | —— | 902,220 | 旧曲线 425,480 → 新曲线后期更陡但收入同步扩容（§2.3） |

**设计依据**：前 30 级刻意压平（1.05），让 26 个主线任务成为节奏器而非刷战斗；61 段起 1.07 保证满级是「月」级目标；三段倍率差 ≤0.02，无断崖感。

### 2.2 经验来源（闭环）

| 来源 | 公式/数值 | 说明 |
|---|---|---|
| 战斗胜利 | `exp = round(关卡锚 / 90)`，首通 ×3 | 78 → 1,756/场，随进度自然扩容 |
| 主线任务 | 直接发 exp（替代原 potion 奖励位） | 1–30 级合计约 4,800（对应分段累计 5,290） |
| 时光屋挂机 | `exp = 1,800 × worldtree / 小时`（受 bonus 加成） | 与金币同源同闸门 |
| 活动/战令 | 按等级带缩放（§9） | 后期不贬值 |

### 2.3 升级接线（落地核心）

- 世界树升级改为：**消耗 `exp_required(L)` + 金币小额**（金币 = `worldtreeCost(L) × 0.2`，见 §3.1）；
- `growth_bp` 曲线由 `10000 + 6000×(L-1)/99`（1.0→1.6）改为 **`10000 + 16000×(L-1)/99`（1.0→2.6）**，并接入 `characterBattleStats`（health/attack/defense 同乘），等级重新成为战力主轴；
- 暴击/抗性增量保留（+30/+25）；assertGrowthConsistency 公式同步改。

### 2.4 经验药剂正名

`potion` 更名定位为**升星/突破材料**（现有 ascendCost 唯一消费方），文案从「经验药剂」改为「灵味原浆」；不再发放「经验」语义的药剂，杜绝概念错位。

### 2.5 100+ 级（无墙延伸）

- 曲线以 1.07 续接（L100 起基数取 L99 需求 60,630），每 50 级一个「轮回段」；
- 无尽层战力锚 = 350,000 × 1.06^层数，与曲线同构，理论上支持到 300+ 级（单级需求 < 5,000 万，数字规模仍受控）。

## 三、经济系统（根治 1.5^L 膨胀与卡墙）

### 3.1 世界树成本：指数 → 多项式

```ts
function worldtreeCost(level: number): { coins: number; leaves: number } {
  return { coins: Math.round(28000 * level ** 1.55), leaves: Math.round(15 * level ** 1.55) };
}
```

| L→L+1 | 旧成本（金币） | 新成本 | 当期日产出 | 回本 |
|---|---|---|---|---|
| 1→2 | 120,000 | 28,000 | 67.7 万 | 0.50 天 |
| 10→11 | 691 万 | 99.3 万 | 107 万 | 0.93 天 |
| 20→21 | 4.6 亿 | 290.9 万 | 186 万 | 1.56 天 |
| 29→30 | **102 亿** | 517.5 万 | 258 万 | 2.01 天 |
| 全程累计 | ≈1.7 万亿 | 6,146 万 | —— | 单调平滑，无墙 |

**设计依据**：多项式阶数 1.55 保证「回本天数」随等级单调缓升（0.5→2 天），永不见底；数字规模压低三个数量级，防 UI/存储膨胀。

### 3.2 挂机产出（与世界树成本同曲线族）

```ts
coins/小时 = 15000 × (1 + 0.22 × (worldtree - 1)) × bonus      // bonus = 1 + 0.05×(树-1) + 0.02×星位（保留）
exp/小时   = 1800 × worldtree × bonus
灵味原浆/小时 = 4200 × (1 + 0.12 × (worldtree - 1)) × bonus
```
离线上限 8/12 小时保留；产出阶数（线性）< 消耗阶数（1.55），长期略有盈余压力 → 引导战斗/任务补充。

### 3.3 食灵精华（leaf）收支重校

- 累计需求：世界树 3.3 万 + 升星 90×star/级（满星约 2.7 万/只）+ 装备强化 → 全程约 12 万；
- 现有来源（任务/关卡/交易 480/日）约 4–5 万 → **缺口约 7 万**；
- 补法：① 装备分解返还 30% leaf（原 only 金币）；② 每日任务新增 leaf 档 ×2；③ 关卡复刷 leaf 掉落按锚点/2000。

### 3.4 货币闸门（全部保留 + 新增 2 条）

| 闸门 | 状态 |
|---|---|
| 关卡复刷收益 20% 断崖衰减 | 保留（防刷单图） |
| 灵晶/契约不可 farm（只从首通/任务/付费） | 保留 |
| 商店/交易/市场限购锁死每日产出 | 保留 |
| **新增**：金币单日获取上限 = `20 万 × (1 + 0.3×worldtree)`（软上限，超出部分转化 exp 50%） | 防脚本/活动叠加爆仓 |
| **新增**：等级差保护——战斗 exp 随（关卡锚 ÷ 玩家可达战力）衰减，碾压刷取收益减半 | 防低级图刷级 |

### 4.2 强化：上限 5 → 12

```ts
MAX_ENHANCEMENT = 12;
强化加成：属性 × (1 + 0.12 × level)          // +12 → ×2.44
强化成本：coins = 3000 × rank × (level+1) × 1.35^level；leaves = 10 × rank × (level+1)
```
后期每级成本约 6 万→42 万金币，构成主要金币消耗口（对冲膨胀）。

### 4.3 副属性洗练（新增，60 级解锁）

- 每件装备 1 条副属性（池：暴击/抗性/速度/命中），洗练消耗金币 `2 万 × (1+0.5×洗练次数)`，数值在 `2–6%` 区间重随；
- 作为后期金币的第二消耗口 + 追求线。

## 十一、关键数值设计依据（速查）

1. **经验分段 1.05/1.06/1.07**：1-30 让位任务节奏（首日 12–15 级实测达成）；满级 4–6 周符合休闲卡牌生命周期；倍率差 ≤0.02 无断崖。
2. **战斗 exp = 锚/90**：首战 78 exp ≈ 1 战 1 级的初期多巴胺；终章 1756/场使尾段每级 ≤1 天。
3. **世界树 28000×L^1.55**：多项式保证回本 0.5→2.0 天单调缓升（验算表见 §3.1）；相比 1.5^L 数字缩小 1974 倍。
4. **growth 1.0→2.6**：战力锚跨度 22.6 倍 = 等级 2.6 × 升星 2.12 × 占星 1.12 × 装备 3.2 ≈ 19.7 倍，余量由技能/阵容补齐——四系统共同承担，单一系统不膨胀。
5. **装备 ×1.85/阶**：两阶之间战力台阶 ≈ 新解锁技能台阶，形成「升级→换装→解锁」三拍节奏。
6. **金币双消耗口（强化+洗练）**：后期产出↑而无消耗是膨胀根源，两口合计可吸收日均产出的 60–70%。

## 十二、落地映射（建议顺序）

1. **v17 迁移**：worldtree 上限 30→100（players CHECK 重建）+ 掌灶人等级=世界树语义合一；exp_required 消费接线（后端 upgrade 接口 + 前端 upgradeTree 改造）；

3. **前端**：upgradeTree/worldtreeCost/idleAccrual/craft 换新公式；characterBattleStats 接 growth_bp 与职业权重；装备洗练 UI；
4. **回归门禁**：现有 143 测试 + 新增「节奏断言」（每级回本 ≤2 天、满级周期 4–8 周、锚点可达性）三组数值测试。

> 分工建议：§2（经验接线）与 §3（经济曲线）先行，是其余一切的地基；装备/技能/敌人数值可随 31–100 关卡扩容（main-quest-design §6）同批落地。
