# 美食大乱斗 · 灵界幻想

基于 React 19、TypeScript、Vite 7 和 Tailwind CSS 4 的幻想题材前端演示，包含 30 个可直达界面，以及相互连接的战斗实况、结算与回放状态。

> **目录说明**：本目录为 monorepo 中的前端工程，后端服务与数据库位于同级 `../backend`。
> 依赖安装与常用脚本请在仓库根目录执行（`npm install`、`npm run dev`）；若就在本目录操作，
> 下文命令依然有效，只是 `npm ci` 需改用根目录的 `npm install`。
> 开发期前端通过 Vite 代理把 `/api` 转发到后端，因此业务代码里直接请求同源 `/api/...` 即可。

本项目将十张参考图对应的场景实现为独立的前端状态，并提供完整的本地体验流程。插画为重新制作的主题素材，界面为响应式重设计，不是原图逐像素复刻，也不是可直接发布的微信小游戏原生工程。

## 启动与验证

- 安装依赖：`npm ci`
- 开发预览：`npm run dev`
- 类型检查：`npx tsc --noEmit`
- 生产构建：`npm run build`
- 构建预览：`npm run preview`
- 安装测试浏览器：`npx playwright install --with-deps chromium`
- 浏览器测试：`npx playwright test`

构建产物位于 `dist/`。部署时上传整个目录，包含 `images/`、`fonts/` 以及 `index.html`，使用 HTTP 静态服务访问。界面默认使用随项目保存的 JPG 原图，避免在预览环境清理 WebP 文件时出现空白；仓库保留 WebP 优化版及新增活动插画。首屏按桌面、手机分别预加载。图片与字体路径按当前文档地址解析，因此根目录或 `/xiaoyouxi_A/` 等子目录部署均可加载。窄屏 320×568 机型下启动协议、开始按钮、主城导航及弹窗关闭按钮保持可见。

## 已实现的前端流程

- 协议勾选校验、协议与隐私说明、服务器筛选及选择。
- 2 至 8 位角色名称校验、随机名称、形象选择、账户修改及本地重置。
- 三步新手引导、跳过引导、主城导航、食灵图鉴、行囊和本地模拟召唤。
- 单一弹窗状态，支持关闭按钮、点击遮罩、Esc 关闭和键盘焦点限制。
- 契约与等级礼包页签切换、首充三日奖励、每日充值档位切换。
- 主城分频道聊天、独立私聊记录与草稿、好友申请与移除、邮件附件领取、任务分组筛选与进度领奖。
- 研制坊炼制经验药剂（含熟练度加成）、时光屋离线累积、集市每日货架与兑换。
- 占星星图逐级点亮、世界树升级提升产出加成与离线上限。
- 活动中心含战令等级与逐级领奖、超值基金里程碑、精选特权状态、吃货卡包抽取。
- 交易坊资源兑换带每日次数上限，次日零点随货架一同重置。
- 街巷食神记按当日领取结算的远征胜场累积进度，进度和领取记录在本地午夜重置。
- 开服活动汇总六项演示活动，可一键跳转；倒计时按本地日历实时显示，不会关闭活动入口。
- 可领取奖励的入口自动显示红点角标，领取后实时递减或消失。
- 灵晶商城以演示额度兑换灵晶，确认页明确说明不会真实扣款。
- 升星豪礼消耗药剂与精华，三星赠徽章、五星赠契约。
- 主城顶部滚动公告仅作展示，点击侧栏公告可阅读完整说明。
- 刷新后回到上一次所在界面（有角色时直接进入主城）。
- 世界树升级消耗金币与精华，影响本地离线产出与离线时长上限。
- 主角装备栏与行囊已接通：开启宝箱、穿戴替换、属性比较、一键最优穿戴、强化及确认分解均更新本地存档。好友与协会流程在本地模拟，不接真人社交服务。
- 所有演示充值均需二次确认，展示“不产生真实扣款”的明确说明。
- 本地奖励发放、资源变动、重复领取保护、首充和七日奖励的日历解锁。
- 设置中的界面色调、粒子开关、音量以及用户主动开启的本地合成氛围音。
- 手机与桌面布局、入场和粒子动画、系统减少动态效果偏好。
- 全部界面具备可访问名称与表单标签；插画和字体设有自动化体积预算，避免部署包无提示膨胀。

## 战斗与回放

- 从主城底部“战斗”或 `/?view=19` 进入远征。选择 1 至 3 位已拥有食灵，调整队伍后出发。
- 新增初春试炼，可用初始青团完成，无需演示充值。更高难度关卡可通过食灵升星、占星和旅者装备提高战力。
- 战斗按固定随机种子生成逐回合记录，展示攻击、技能、治疗、暴击、生命变化与退场。回放读取相同记录，不重新随机结果。
- 支持自动播放、暂停、1x/2x 速度、逐步播放、进度拖动、重新播放和跳至结算。减少动态效果模式默认暂停，仍可手动播放。
- 战斗期间不发奖；胜利后在独立结算页领取战利品。失败只收录战报，不增加货币、胜场或活动进度。
- 每关首次胜利获得完整奖励，后续胜利获得对应资源的 20%。同一战斗 ID 只能结算一次，重复点击和回放不重复发奖。
- 未结算战斗保存在本地，暂离、关闭页面或刷新后，可通过远征页“继续远征”恢复。不会被新战斗覆盖。
- 主城左侧“录像”或 `/?view=14` 展示最近 20 场实际结算记录，支持胜负筛选和逐回合回看；没有战报时显示空状态，而不是虚构历史。
- 跨午夜结算的旧战斗仍可领取资源，但不增加新一天的街巷食神记进度。

## 装备与行囊

- 从底部“主角”或 `/?view=16` 查看旅者行装；从右侧“背包”进入行囊的物资、宝箱和装备页签。没有额外增加参考图编号。
- 创建角色后可免费领取一次六只启程宝箱，不需要模拟充值；旧存档同样可以领取一次。
- 每只宝箱获得一件装备，依次覆盖武器、头饰、衣甲、饰品、秘宝、徽记六部位。每六只补齐一轮部位，不保证同一品质。
- 品质概率为稀有 60%、史诗 35%、传说 5%。所有开启仅在本地演示，不涉及真实付费抽取。
- 支持开启一只或五只；按实际数量扣除宝箱，记录最近一次结果，并限制装备容量为 120 件。没有宝箱或空间不足时不会扣除资源。
- 装备行囊支持部位筛选、战力或获得时间排序，详情展示与当前部位的属性差值。替换和卸下不会销毁旧装备。
- 一键最优穿戴仅替换同部位战力更高的装备，不会把已穿戴装备降级。未穿戴的装备不计入战力。
- 强化最高 +5，消耗金币和食灵精华。事务检查预期强化等级，旧界面的重复请求不会连续扣除资源。
- 只有未穿戴装备可分解，需二次确认；分解删除实例并返还界面标示的金币，同一实例无法重复分解。
- 旅者装备为队伍共享加成，实际影响出战食灵的生命、攻击、防御、速度、暴击和抗暴。主角属性以阵容首位食灵为基准展示。
- 战斗开始时保存属性快照。战斗中途更换装备不会改变已保存的回合、结果或战报；装备变化在下一次出战生效。
- 装备、穿戴、强化和开启记录在刷新及每日重置后保留。读取旧存档时自动补充装备字段，不清空角色和原有资源。

## 存档边界

- 每日额度、集市、交易次数和限时活动按各自日期独立重置。页面保持打开、从后台回来和执行资源操作时均检查日期。
- 长期进度（角色、星级、食灵、装备、首通记录、战报和未结算战斗）不会被每日重置清空。
- 交易上限、升级消耗和重复领取在更新状态时再次校验，不只依赖按钮禁用状态。
- 读取旧存档时补充新字段，移除未知食灵和无效数值，拒绝损坏的战斗记录，保留有效进度。
- 盛宴卡包额外的两份契约会正确入账，且抽取范围限定为 SSR。重复食灵不会凭空增加碎片或虚假资源。

## 好友与协会

- 继续使用已有入口：左侧“好友”（`/?view=15`）、“聊天”（`/?view=11`）及底部“协会”（`/?view=18`），没有增加页面编号。
- 所有联系人、在线状态、协会人数与示例发言均为预设演示内容。初始青团为本地伙伴，半盏桂花茶提供一份明确标注的演示邀请。
- 好友页面支持名字或编号搜索、结识旅人、查看申请、撤回、婉拒及接受。发出的申请不自动通过，须明确点击“模拟对方同意”。
- 确认移除好友后，其私聊不可继续写入，但历史记录不会被悄悄删除；重新结识后可继续查看。
- 聊天的世界、协会与私聊记录彼此隔离。不同私聊对象、不同协会也使用独立会话键，不共用记录和草稿。
- 所有新发言只保存你主动输入的文本，页面不会自动扮演真人回复，也不显示虚假的“已送达”或“已读”状态。
- 每条消息最多 120 个字符；每个会话最多保存 80 条，总计最多 200 条。草稿按会话保存，刷新后可继续编辑。
- 支持 Enter 保存、Shift+Enter 换行及输入法组合输入。空白、过长、无效频道和重复消息请求会在状态更新时再次校验。
- “清空本频道记录”需要确认，只清空该会话中你保存的发言，其他会话和明确标注的示例发言不变。
- 协会申请只在当前设备记录，刷新后保留。须点击“模拟审批通过”才加入，未加入协会不能写入协会频道。
- 加入后可查看预设成员、打开协会频道、签到、捐献及查看本地操作日志。签到增加 5,000 金币与 20 贡献；捐献消耗 10,000 金币并增加 30 贡献。
- 每位旅者每日只能签到和捐献各一次，退出或更换协会不会重置次数。个人贡献、历史会话与当天领取记录会保留。
- 以上均为浏览器内的单机流程，没有好友匹配、真人会长审批、多人在线、私信投递或社交服务器。

## 数据与范围

角色、服务器、奖励和偏好保存在当前浏览器的 `localStorage` 中。页面不调用支付、登录、游戏服务器或第三方统计接口。

- `food-fantasy.save.v1`：角色、资源、装备、战报、领取记录及 `social` 本地好友、会话、草稿和协会状态。
- `food-fantasy.preferences.v1`：配色、粒子和音量偏好。
- `food-fantasy.session.v1`：上次所在的启动页或主城。
- 每日额度按设备本地日历日期重置；七日和首充奖励按创建或购买日期解锁。
- 模拟召唤只更新本地食灵图鉴；相同食灵不会重复计数。
- 战斗为本地回合制模拟，不包含真实游戏战斗服务器、正式微信认证、真实充值、跨设备同步或后端防作弊。本地存档可由使用者修改，不能用作正式运营的可信账本。
- 页面中的服务器状态和排行榜均为明确标注的样例数据。
